How does the scale operator log in?

The tablet stays at the scale all day. What level of access control do you need?

A

Kiosk PIN — shared station code

A single 4–6 digit PIN unlocks the station for the shift. The app auto-locks after inactivity. No individual user accounts needed on the tablet.

Pros

  • Fastest for operators — one PIN, done
  • Tablet never shows the main portal
  • PIN set by admin in settings

Cons

  • No per-operator audit trail (just "scale station")
B

Standard login — new "scale_operator" role

Each operator logs in with their own username + password. A new role scale_operator is added — restricted to the scale station routes only.

Pros

  • Full per-operator audit trail
  • Individual accountability
  • Fits the existing NextAuth user system

Cons

  • Operators must type username + password on a touchscreen
  • Slightly more setup for admin
C

Hybrid — standard login + quick PIN re-lock

Operator logs in once per shift with username + password. The screen then auto-locks with a personal PIN after inactivity — no full re-login needed mid-shift.

Pros

  • Best of both: individual accountability + fast unlock
  • Fits existing PinLockStore already in codebase

Cons

  • Slightly more complex setup

💡 My recommendation: Option B — a dedicated scale_operator role keeps the audit trail clean and reuses the existing auth system with minimal extra code.
