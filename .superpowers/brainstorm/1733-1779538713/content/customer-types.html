Which customer types does the scale station handle?

The existing system has two customer types. What should the operator be able to select at the scale?

A

Casual only

The scale station always creates a quick walk-in customer record (name, surname, contact, address). No account lookup needed.

Pros

  • Simplest flow — no search or lookup step
  • Fastest for high-volume walk-in yards

Cons

  • Can't link a weigh-in to an existing account customer
B

Casual + Account lookup

Operator chooses: enter new casual details, OR search for an existing account customer by ID number / phone.

Pros

  • Handles regular dealers and account holders
  • Links weigh-in to existing customer profile

Cons

  • Slightly more steps for account customers
  • Operator needs to know customer's ID/phone

💡 My recommendation: Option B — even if 90% are casual, the ability to look up an account customer future-proofs the station and prevents duplicate records for regulars.
